# Vector Videogames

Tienda eCommerce en **React** (Vite). Catálogo cargado desde `public/products.json`.

## Requisitos de la semana 7

- Listado de productos con nombre, precio normal, precio oferta, descripción corta e imagen
- Carrito con agregar / eliminar, contador de productos y total
- Estado con `useState` y renderizado condicional

## Requisitos de la semana 8

- Catálogo cargado dinámicamente con `useEffect` + `useState` (con latencia simulada desde `public/products.json`)
- Estados de carga y de error con renderizado condicional
- Botón que cambia de "Agregar al carrito" a "En el carrito" según el estado del carrito
- Toggle "Ver más / Ver menos" para las descripciones largas
- Renderizado condicional del carrito vacío

## Cómo correrlo

```bash
npm install
npm start
```

Abre la URL que muestre Vite (por defecto `http://localhost:5173`).
